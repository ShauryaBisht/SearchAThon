# SearchAThon 🚀

A full-stack collaboration platform designed to connect developers, designers, and innovators to form balanced, high-impact teams for hackathons.

---

## 🎯 The Problem

Finding the right teammates for hackathons is often fragmented across messy Discord channels, WhatsApp groups, and LinkedIn posts. **SearchAThon** streamlines matchmaking by letting participants discover projects based on required skills, send join requests, and assemble ready-to-compete squads.

---

## ✨ Key Features

- **Hackathon & Team Discovery:** Browse active hackathons and open teams looking for specific skill sets.
- **Join Request Workflow:** Send, accept, or reject membership requests with real-time status tracking.
- **Skill-Based Matching:** Filter candidates and squads by role (Frontend, Backend, UI/UX, AI/ML, etc.).
- **User Profiles & Portfolios:** Showcase technical skills, past hackathon experience, GitHub profiles, and resume links.
- **Fast In-Memory Caching:** High-throughput caching for popular listings and active searches powered by Redis.
- **Media Uploads:** Cloud-hosted team banners, profile avatars, and project submissions managed via Cloudinary.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Caching & Performance:** Redis
- **Media Storage:** Cloudinary
- **Authentication:** JWT (JSON Web Tokens) & HTTP-only cookies
